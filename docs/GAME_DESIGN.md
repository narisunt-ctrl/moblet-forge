# Moblet Forge — เอกสารการออกแบบเกม

ผู้คิดและออกแบบเกม: **นริสันต์ นาคะเกศ (Narisan Nakakes)**

## แนวคิดหลัก

> ผู้เล่นไม่ได้เขียนพฤติกรรม แต่เขียน "คุณค่า" แล้วให้ตัวละครเรียนรู้พฤติกรรมเอง

เกมสร้างเกมทั่วไปให้ผู้สร้างสั่งตัวละครว่าต้องทำอะไร Moblet Forge กลับด้าน: กฎเหตุการณ์ทุกข้อเป็นรางวัลหรือโทษ
และโมบเล็ตเรียนรู้ทางผ่านด่านด้วย Reinforcement Learning ความสนุกจึงอยู่ที่การเห็นผลจากการตั้งคุณค่า
ทั้งตอนที่ได้ผลตามที่ตั้งใจ และตอนที่ AI หาช่องโหว่ของกฎ (reward hacking)

## สูตรการเล่นที่ 1: โรงตีเกม (Creator)

วาดด่าน → ตั้งกฎ → ออกแบบตัวละคร → ฝึก → เล่นแข่งกับ AI → ส่งออกเป็นเกมไฟล์เดียว

## สูตรการเล่นที่ 2: ภารกิจครูฝึก (Coach Quests)

โหมดปริศนาที่ผู้เล่น **บังคับโมบเล็ตเองไม่ได้เลย** ทำได้อย่างเดียวคือเป็นครูฝึก

### กติกา
1. แต่ละภารกิจมีด่านตายตัว **กฎที่ล็อกไว้** (แก้ไม่ได้ บางข้อเป็นตัวหลอกล่อ) และ **เป้าหมาย** ที่ใช้ตัดสิน
2. ผู้เล่นเขียนกฎของตัวเองได้ภายใต้ **งบคะแนน**: ผลรวมของ |คะแนน| ของทุกกฎต้องไม่เกินงบ และจำนวนกฎมีจำกัด
3. เลือกวิธีเรียนรู้ได้ Q-learning (กล้าเสี่ยง หาทางที่ดีที่สุดตามทฤษฎี) หรือ SARSA (ระวังตัวระหว่างฝึก)
4. กด **ส่งตรวจ** ระบบจะล้างสมอง ฝึกใหม่ด้วย seed คงที่ และตรวจทุกช่วงรอบ (checkpoint)
5. ตัดสินจาก **เป้าหมายของภารกิจเท่านั้น** ไม่ใช่คะแนนที่ผู้เล่นตั้ง กฎ "จบรอบ/ชนะ" ของผู้เล่นจึงโกงผลไม่ได้

### ดาว
- ★ ผ่านภายในจำนวนรอบฝึกที่อนุญาต
- ★★ ผ่านเร็ว (ภายในเกณฑ์รอบแรก)
- ★★★ ผ่านเร็วมาก ต้องออกแบบรางวัลให้สอนง่าย ไม่ใช่แค่ถูก

### ทำไมสนุก
ทุกภารกิจมีคำตอบที่ "ดูเหมือนถูก" แต่ผิด ผู้เล่นต้องเข้าใจว่า AI คิดอย่างไร:

| ภารกิจ | กับดักที่ออกแบบไว้ | บทเรียน |
|---|---|---|
| 1 ก้าวแรกของครูฝึก | ไม่มีรางวัล = AI ไม่รู้ว่าอะไรดี | ต้องให้สัญญาณรางวัล |
| 2 อย่าเหยียบหนาม | โทษหนามเบาเกินไป AI ไม่เคยสำรวจทางอ้อม | โทษต้องหนักกว่ารางวัล หรือใช้ SARSA |
| 3 นักสะสมถ่านไฟ | ให้รางวัลถ่านไฟแต่ตะเกียงจบรอบทันที | ใช้เงื่อนไขคู่ "ครบ/ยังไม่ครบ" |
| 4 ลมส่งตัว | กฎล็อก +0.5 ต่อถ่านไฟ ล่อให้เดินอ้อม | ค่าต่อก้าวต้องแพงพอจะชนะสิ่งล่อใจ |
| 5 สะพานโคลนลื่น | โคลนเป็นทางลัดแต่ลื่นตกหนาม 10% ต่อก้าว | ชั่งความเสี่ยงในโลกที่สุ่ม |
| 6 กุญแจทางไกล | กฎล็อก +0.1 ทุกก้าว โมบเล็ตชอบเดินเล่นจนหมดเวลา | ต้องหักล้างรางวัลที่ผิดทิศ |

ทุกภารกิจมีชุดทดสอบใน `test/quests.test.js` ยืนยันว่า (1) มีคำตอบภายในงบ (2) กฎว่างไม่ผ่าน และ (3) คำตอบที่ดูเหมือนถูกถูกปฏิเสธจริง

## ช่องพิเศษในด่าน

| ช่อง | กลไก |
|---|---|
| ลมพัด | ดันต่ออีกหนึ่งช่องในทิศที่เดิน (behavior หลังขยับ) |
| โคลนลื่น | ก้าวที่ออกจากโคลนมีโอกาส 40% ไปทิศสุ่ม ทำให้โลกเป็นแบบสุ่ม (behavior ก่อนขยับ) |
| กุญแจ / ประตู | ประตูเดินผ่านได้เมื่อมีกุญแจ สถานะกุญแจเป็นส่วนหนึ่งของ state |
| ถ่านไฟ | เก็บได้ครั้งเดียวต่อรอบ จำใน bitmask (สูงสุด 8 ก้อน) |
